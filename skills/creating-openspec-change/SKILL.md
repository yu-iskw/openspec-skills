# Creating OpenSpec Change

Initializes a new change proposal under `openspec/changes/<name>/`. Use slug-style names
(e.g., `add-dark-mode`, `user-auth`).

## Commands

| Command | Flags | Notes |
|---------|-------|-------|
| `npx @fission-ai/openspec@latest new change <name>` | — | Create a new change directory |
